# Videos generados

Sube aquí los MP4 originales. Esta es la carpeta `shots/` indicada en las tarjetas de generación.

## Nombre de cada video

Usa `EP01_SH01_V1.mp4`: episodio 01, plano 01, intento 1. Para otro intento usa `V2`, `V3`, etc. Conserva los originales; la copia elegida para montaje llevará el sufijo `_FINAL.mp4`.

## Identificar el prompt y la imagen usados

Por cada MP4, copia `PLANTILLA_FICHA.md` a un archivo con el mismo nombre base; por ejemplo, `EP01_SH01_V1.md`. Completa el prompt y la imagen que realmente usaste. El nombre del video identifica el plano, pero no permite saber por sí solo qué herramienta, prompt o imagen utilizaste.

Para la primera prueba **EP01_SH01**, el plan del proyecto indica:

- Video que debes subir: `EP01_SH01_V1.mp4`.
- Prompt previsto: [EP01_SH01_KLING.txt](../VIDEO_PROMPTS/KLING/EP01_SH01_KLING.txt).
- Imagen inicial prevista: [COAT_START.png](../SHOT_REFERENCES/COAT_START.png).
- Ajustes y alternativas: [tarjeta EP01_SH01](../EPISODES/EP01/GENERATION_CARDS/EP01_SH01.md).

Estas son referencias previstas, no una confirmación de lo usado. Si elegiste otra herramienta o cambiaste algo, anótalo en la ficha. Si modificaste el prompt, guarda el texto exacto junto al MP4 como `EP01_SH01_V1_PROMPT.txt`. Si usaste otra imagen, adjúntala también e indica su nombre.

En GitHub, entra en esta carpeta y usa **Add file → Upload files** para subir el video y su ficha. Puedes subir primero el video y completar la ficha después; mientras tanto, su origen queda pendiente de confirmar.
