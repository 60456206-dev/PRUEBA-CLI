# Continuidad del trabajo

Antes de trabajar en este repositorio, lee `ESTADO_PROYECTO.md` para retomar el contexto y los acuerdos con el usuario. Comprueba los archivos y el estado de Git antes de afirmar que falta un archivo; revisa el historial si hay discrepancias.

Actualiza ese resumen cuando cambie el plano activo, se elija una versión o quede una decisión pendiente. Mantenlo breve y distingue archivos generados, revisados y aceptados. Las nuevas instrucciones del usuario tienen prioridad.

Por petición del usuario, revisa visualmente cada imagen generada antes de entregarla y compárala con el objetivo del plano, sus referencias y su continuidad. Indica cualquier diferencia relevante; no des por validada una imagen solo porque la generación terminó.

## Oficialización de vídeos

Cuando el usuario diga «oficializar», «es oficial» o «me quedo con esa versión», preparar el vídeo elegido: comprobar identidad, ajustar a duración de montaje si corresponde, verificar duración/decodificación y continuidad, renombrar `EPxx_SHxx_FINAL.mp4`, actualizar tarjeta y estado y eliminar vídeos descartados del mismo plano tras verificar el oficial. No borrar otros planos ni referencias. Sustituye el acuerdo anterior de aplazar nombres finales.
