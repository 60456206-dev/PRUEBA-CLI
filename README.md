# PRUEBA-CLI

## PULSO — juego de ritmo

[Abrir el juego](https://pulso-local-rhythm.marco36gonzales.chatgpt.site).

Carga tu música local y juega con **D, F, J, K** o los controles táctiles. Incluye tres dificultades, una pista de prueba, ajuste de sincronización y récords locales.

Para ejecutarlo aquí: `cd pulso && npm start`, luego abre `http://localhost:4173`. Consulta [las instrucciones de PULSO](pulso/README.md).

El contexto de los demás trabajos del repositorio está en [ESTADO_PROYECTO.md](ESTADO_PROYECTO.md).
